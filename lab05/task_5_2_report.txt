Лабораторна робота 5.2 — алгоритм малих і великих кроків
===========================================================================

Задача дискретного логарифма:
Знайти x з рівняння: 5^x ≡ 8 mod 23

Параметри групи:
p = 23
Бінарна довжина p: 5
a = 5
b = 8
Порядок групи G = <a>: 22
m = ceil(sqrt(order)) = 5

Результат алгоритму:
Знайдено збіг при i = 1, j = 1
x = i*m + j = 1*5 + 1 = 6
Перевірка: pow(a, x, p) = 8
Очікуване b = 8
Результат правильний: True

Перевірка повним перебором:
x, знайдений brute force: 6
Збігається з BSGS: True

Baby steps: значення a^j mod p
j =   0, a^j mod p = 1
j =   1, a^j mod p = 5
j =   2, a^j mod p = 2
j =   3, a^j mod p = 10
j =   4, a^j mod p = 4

Giant steps: значення b * a^(-i*m) mod p
i =   0, gamma = 8
i =   1, gamma = 5

Висновок:
Було реалізовано алгоритм малих і великих кроків для знаходження дискретного логарифма в групі G = <a>. Алгоритм зменшує складність порівняно з повним перебором з O(N) до O(sqrt(N)) за часом і пам'яттю.
